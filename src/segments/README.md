## How to revise with ChatGPT

You can say things like:

- “Edit `01-hero.html`: make the headline shorter.”
- “Show me a new version of `04-centres.html` with 3 centres instead of 4.”
- “Change only `06-research.html`; don’t touch the other sections.”

This makes visual revisions much safer because each request has a clear boundary.
